# Moonlight Peaks: Tool Upgrade Guide

All at Howling Hammer (Ridge). Mon-Fri 6PM-Midnight.

## Pickaxe (#1)
| Tier | Cost | Materials | Effect |
|------|------|-----------|--------|
| Copper | 1,000g | 3 Copper Bars | -20% stamina |
| Iron | 2,000-4,000g | 3 Iron Bars | -35% |
| Gold | 3,500-16,000g | 3 Gold Bars | -50% |
| Enchanted | 48,000g + 5 ME | Gold Pickaxe | Zero stamina |

## Axe & Watering Can: Same costs.
## Shovel, Scythe, Rod: Similar.

## Order: Copper Pick -> Axe -> Can -> Iron -> Gold -> Enchanted.

## Smelting: 5 Ore + 1 Coal = 1 Bar
