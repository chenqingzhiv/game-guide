# Moonlight Peaks: NPC, Friendship & Romance Guide

## Heart Levels
0-2 Acquaintance -> 2-4 Friend -> 4 Dating -> 8 Marriage

## Universal Gifts
Golden Egg, Diamond, Moon Crystal, Rose Quartz.

## Key NPCs
- Dragan (Nokturna, bday Spring 28): loves gems
- Luna (Seeds): loves magical crops
- Ridge (Blacksmith, Mon-Fri 6PM-Midnight): loves metal bars
- Sabrina (Magic): loves Nightshade, Mana Essence
- Orlock (Keg quest): loves wine
- Death (Bug net, Clock): loves Soul Blobs

## Marriage
8 hearts + proposal item + house space. Spouse helps with chores.
