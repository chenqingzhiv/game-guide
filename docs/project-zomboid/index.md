## What is Project Zomboid?

Project Zomboid is a deeply simulated isometric survival horror game from **The Indie Stone**, in continuous development since its 2013 Early Access launch. You are a survivor inside the military-quarantined **Knox Country, Kentucky**, where a virus has reanimated the dead and the only goal is to keep living. Its dense simulation — hunger, thirst, sleep, infection, weather, mood, and permanent death — makes every run a story, and its brutal fairness keeps players coming back after a decade.

The game hit a new all-time high of **121,603 concurrent players** on August 2, 2026, after the **Build 42.20 stable release** (July 29, 2026) doubled the map, added animals and a full crafting overhaul.

## Game Features

| Feature | Description |
|:--------|:------------|
| 🧟 **Zombie Sandbox** | A seamless, simulated open world where every death is permanent |
| ☣️ **Knox Infection** | Bites are 100% fatal, scratches 7% — no cure, no exceptions |
| 🗺️ **Knox Country** | One giant map — towns, farms, forests, and the walled city of Louisville |
| 📺 **Life & Living** | Free skill XP from the in-game TV channel in the first nine days |
| 🐄 **Animal Husbandry** | Cows, sheep, chickens, pigs — raise, breed, milk, shear, and butcher |
| 🔨 **Crafting Overhaul** | 12 disciplines from knapping to blacksmithing to glassmaking |
| 🏗️ **Deep Base Building** | Fortify, barricade, farm, and outlast the winter |
| 🚗 **Vehicles** | Working cars, hotwiring, fuel economy, and car-based survival |
| 👥 **Co-op** | Official multiplayer with dedicated servers and anti-cheat |
