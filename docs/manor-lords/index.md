# Manor Lords 🏰

**Rise from a single settlement to a thriving medieval kingdom.** A historical city-builder where every family matters, every log has to be carried, and your militia defends everything you've built.

[![Manor Lords banner](/assets/images/manor-lords/manor-lords-hero.webp){: .game-hero }](/assets/images/manor-lords/manor-lords-hero.webp)

## What is Manor Lords?

Manor Lords is a medieval city-builder and real-time tactics game by Slavic Magic, published by Hooded Horse. Still in Early Access at **version 0.8**, it models a deep, family-based economy — each worker is a person with a home, a job, and needs — layered with large-scale tactical battles. If you like *Banished*, *Farthest Frontier*, or *Total War*, this sits right between them.

## Game Features

| Feature | Description |
|:--------|:------------|
| 🏘️ **Family Economy** | Every worker is a person — housed, fed, and employed |
| 🌾 **Deep Production Chains** | Wheat → flour → bread; flax → linen; barley → ale |
| ⚔️ **Real-Time Tactics** | Mustering militia and commanding squads in pitched battles |
| ❄️ **Harsh Seasons** | Winter doubles fuel burn; food spoilage is real |
| 🗺️ **No-Grid Building** | Organic placement on a living map |
| 📈 **Development Tree** | Unlock skills as your settlement levels up |
